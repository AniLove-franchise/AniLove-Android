AniList, without the app store.

AniLove is an Android client for AniList: track what you watch, stream episodes from your own sources, and message friends in an Instagram-style inbox that runs on AniList messages. There is no AniLove server — the app talks straight to AniList.

What it does

Everything talks to the services you already have. Nothing talks to us.

📚

Track anime & manga

Your AniList lists, scores, progress and activity, with seasonal charts, schedules and search.

▶️

Watch episodes

Play from your own sources in a native player, with subtitles, gestures, picture-in-picture and downloads.

💬

DMs that run on AniList

An Instagram-style inbox, replies, reactions, seen marks and editing — all stored as AniList messages.

🖼️

Encrypted pictures

Send photos through your own Google Drive, encrypted on the phone. The receiver needs no Google account.

🎞️

GIFs & stickers

Search Tenor and send a GIF in one tap. The link that gets sent is what AniList stores.

🔐

Per-profile sessions

Keep more than one AniList account on the device, each behind an optional PIN, with the tokens kept apart.

Installing

Sideloaded on purpose: no Play Store account, no store review, no store services.

  1. Download the APK with the button above. It always points at the newest release.
  2. Allow installs from this source. Android will ask once; approve it for your browser or file manager.
  3. Open AniLove and sign in with AniList. Sign-in happens on AniList's own page, then comes back to the app.
  4. Optional: connect Google Drive if you want to send pictures. Only the sender needs it.
Updates keep your data. Every release is signed with the same certificate, so new versions install straight over the old one. If Android refuses an update, the APK came from somewhere else — delete it and download again from this page.

Verify the download

Every release lists the APK's SHA-256 in its notes; compare it with certutil -hashfile AniLove.apk SHA256. To check the signer with the Android SDK: apksigner verify --print-certs AniLove.apk. The certificate SHA-256 is always E3:04:A1:D5:2A:6D:27:29:FF:A0:4B:2F:6A:F7:7B:84:3E:CA:C9:99:10:23:A6:E1:99:AE:57:9C:CD:48:00:24. If either value differs, do not install the file.

Privacy in one paragraph

The developer operates no server, no database and no analytics. Your AniList token never leaves the device except to AniList itself. Shared pictures are encrypted with AES-256-GCM before they are uploaded, and the key travels inside the chat message — which means AniList, and the person you are talking to, can read it. That is the honest limit.
